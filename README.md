
# Attendance Shortage Early Warning System

## Project Overview
The Attendance Shortage Early Warning System is a C-based application designed to manage student attendance records and identify attendance shortages.

## Features
- Add student records
- Display all student records
- Search student details
- Update attendance records
- Sort students by attendance percentage
- Set minimum attendance percentage
- Generate attendance shortage warnings
- Save records using file handling

## Technologies Used
- C Programming
- Structures
- Linked Lists
- File Handling
- Dynamic Memory Allocation

## Attendance Criteria
Default minimum attendance: 75%

Students with attendance below the minimum percentage will receive a shortage warning.

## How to Compile and Run

Compile:
gcc attendance.c -o attendance

Run:
./attendance
